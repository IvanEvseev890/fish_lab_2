# Паспорт модели (Model Card)

## 1. Общие сведения
- **Название модели:** HistGradientBoosting + Vproxy (Эксперимент E4).
- **Тип задачи:** Регрессия (предсказание массы рыбы).
- **Автор:** [Твоё ФИО]
- **Дата:** 24.10.2026
- **Версия:** v0.1

## 2. Назначение и ограничения
- **Назначение:** Предсказание веса рыбы (в граммах) на основе её геометрических измерений и вида.
- **Где можно применять:** Рыбные хозяйства, магазины, научные исследования для быстрой оценки массы без взвешивания.
- **Ограничения:**
    - Обучена на данных из одного региона (Токио), может не работать для других видов рыб.
    - Маленький датасет (110 записей), что ограничивает точность для редких видов.
    - Не учитывает сезонность, возраст, условия обитания.

## 3. Данные
- **Источник:** `fish_participant.csv`.
- **Признаки:** `Species`, `Length1`, `Length2`, `Vproxy` (производный от `Length3 * Height * Width`).
- **Целевая переменная:** `Weight` (граммы).
- **Разбиение:** 80/20, `random_state=42`, тест заморожен.

## 4. Архитектура и гиперпараметры
- **Модель:** `HistGradientBoostingRegressor` (градиентный бустинг).
- **Гиперпараметры:** `max_iter=100`, `max_depth=5`, `learning_rate=0.1`, `random_state=42`.
- **Предобработка:** `SimpleImputer` (медиана для числовых, мода для категориальных), `StandardScaler`, `OneHotEncoder`.

## 5. Метрики качества
**На тестовой выборке (20%):**
- MSE: 5694.36
- MAE: 44.54
- R²: 0.9370

**На демо-выборке (`fish_holdout_demo.csv`):**
- MSE: 2227.51
- MAE: 34.89
- R²: 0.9761

**Кросс-валидация (5-fold на train):** CV MSE = 9905.70 ± 3273.81.

## 6. Анализ ошибок
- Наибольшие ошибки — для крупных рыб (>800 г), модель занижает вес.
- Самый высокий MAE у вида Perch (73.73 г), так как окуни имеют большой разброс веса при схожих размерах.
- Отрицательных предсказаний нет.

## 7. Интерпретируемость
- Наиболее важный признак — `Vproxy` (прокси-объём), так как он объединяет три измерения.
- Модель не является причинной: важность признака в дереве не доказывает причинное влияние.
